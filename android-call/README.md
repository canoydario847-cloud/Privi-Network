# Privi Call for Android

A Trusted Web Activity (TWA) that opens the Privi Call web app (`https://privi-call.onrender.com/app/`) full screen in Chrome.
The same app installs from any browser ("Add to Home screen" / "Install app") without Google Play.

- Package: `us.priviflow.call`
- Origin: `https://privi-call.onrender.com` (the server serves `/.well-known/assetlinks.json` for it)
- Built by `.github/workflows/android-call.yml` (unsigned unless signing secrets are set)
- Generated by `apps/build.py` from `apps/apps.json`. Change those, not the files here.

## Release steps (owner only)

1. **Upload key.** On your computer: `keytool -genkeypair -v -keystore call-upload.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000`.
   Keep the file and password safe and off GitHub. Optionally add GitHub secrets `CALL_KEYSTORE_B64` (base64 of the
   .jks) and `CALL_KEYSTORE_PASSWORD` so the workflow signs the bundle for you.
2. **Build.** GitHub → Actions → "Privi Call Android app" → Run workflow. Download the `.aab` from the run.
3. **Play Console** (account PriviKing1) → Create app → "Privi Call", App, Free to download → upload the .aab to
   **Internal testing**.
4. **App signing fingerprint.** Play Console → Test and release → App integrity → copy the **App signing key
   SHA-256**. In Render, set `CALL_ANDROID_SHA256` on privi-call to that value (comma-separate if you add the upload-key SHA-256
   too). Until this is set the app still works, but shows a browser bar at the top.
5. **Store listing, Data safety, content rating, privacy policy URL**, then roll out. Personal developer accounts
   must run a **closed test with at least 12 testers for 14 days** before Google allows a production release.

## Suggested listing

**Title:** Privi Call
**Short description:** Pre-call checks: do-not-call list, calling hours and consent records.
**Full description:** Privi Call answers one question before anyone dials: go or no-go. Keep your own do-not-call list. Check that it is between 8 a.m. and 9 p.m. where the called person is. Record who agreed to marketing calls, an AI voice, call recording or texts, in a log that cannot be back-filled. Phone numbers are stored only as salted fingerprints. These checks cover your own records; they do not check the National Do Not Call Registry and are not legal advice. Each use is paid in USDC from a crypto wallet.
**Icon:** `play-store-icon-512.png` in this folder.

## Things to know before submitting

- Payment for the service happens on the web (a Privi key or plan, or USDC from a crypto wallet), not through
  Google Play billing. Check Google Play's current payments policy for your case before you submit.
- Pay-per-use with a wallet does not work inside the Play app itself, because Chrome on Android has no wallet. The
  app offers an "Open in MetaMask" link for that; customers with a key or plan are not affected.
