## First-use success definitions

1. **Human trial:** A real person checks Guard or inspects Scan. A page impression alone is not proof of product use.
2. **Agent trial:** A real agent calls a Privi MCP tool. A read-only call without authorization is enough to start.
3. **Integrated agent:** A genuine organization signs up, configures its private key, records an actual tool call, then reads the receipt.
4. **Paying customer:** A separate organization completes a real settled purchase. Neither self-tests nor founder-funded purchases count as third-party revenue.

## Outreach sequence (permission-based, not bulk spam)

- Offer 3–5 teams a free 90-day assisted pilot for one narrowly defined workflow.
- Invite 20 developers who already publish MCP/x402 integrations to try one free call and report issues; personalize each invitation.
- Share the start page and repo example in MCP developer communities where self-promotion is permitted.
- Submit or claim Privi listings in Smithery, PulseMCP, Glama, mcp.so, Cursor, Cline, and the x402 ecosystem according to each directory's submission rules.
- After each trial, record opt-in status, actual API calls, successful write/read receipts, errors, opt-out, and next follow-up date in a private CRM. Do not store private credentials or expose personally identifying usage data publicly.
