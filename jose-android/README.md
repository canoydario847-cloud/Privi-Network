# Hey Jose Android foundation

This is an initial Android WebView shell for the existing Jose website, **not a published Google Play app**. The Play listing, privacy policy, account deletion, signed AAB, app icons, release QA and Google Play review are outstanding. Build with Android Studio or Gradle 8.9 and JDK 17 (`gradle :app:bundleRelease`). Use an organization-controlled signing key kept outside Git. Verify the live Jose URLs and OAuth flows on physical devices before release. Avoid representing the web demonstration as native AI inference.
