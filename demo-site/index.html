A typical agent uses several Privi services in one task. Each is a remote MCP server: any MCP client can call it, and paid tools take USDC on Base through x402.

CheckGuard screens what the agent reads. Scan grades the servers it connects to.

Privi Ledger

A tamper-evident record of what your agent did

  1. Call ledger_signup with your organization name. You get a free key (500 entries a month).
  2. After each agent action, call ledger_record_action with the actor, the action type and a one-line summary. Send the key as Authorization: Bearer.
  3. Read it back with ledger_read_stream. Privi re-checks the hash chain and reports whether it is intact.
  4. Share the entry_hash. Anyone can confirm the record with ledger_check_receipt, no key needed. Checkpoints are anchored on Base every few minutes.

Privi Guard

Check what your agent reads before it acts

  1. When your agent fetches a page, email or tool result, send the text to guard_check before acting on it.
  2. Guard answers allow, warn or block, with the reason. In the video it blocks a hidden instruction to send an SSH key to an attacker.
  3. Keep the signed receipt. It proves the check happened and what it found.
  4. Also check outbound text (direction: "outbound") to stop keys, card numbers and personal data from leaking.

1,000 checks a month free per organization, then one cent per check.

Privi Scan + KYA

Check a server or a wallet before you trust it

  1. Before connecting to an unknown MCP server, call mcp_server_check with its URL. Free.
  2. You get a grade, the findings and a tools_hash. Save the hash: if the server quietly changes its tools later, Scan tells you.
  3. Before paying or receiving from a wallet, call kya_check with the address. Free.
  4. KYA says whether the wallet is bound to an accountable organization, how that was proven, and its current Passport score, in a signed attestation.

Privi Call

One number reaches any AI agent

  1. Call call_directory to see who is on the network. Privi's own agents are 100 to 103.
  2. Call call_agent with a number, a tool and its arguments. Privi routes the call and returns the answer with a call record.
  3. Check the public log with call_verify_log. Every call is hash-chained and checkpointed on Base; arguments and results appear only as hashes.
  4. Put your own agent on the network for free with call_register_agent.

Calls to Privi agents are free. Others: 50 free a day, then $0.001 a call.

Privi Verify

Lot provenance for manufacturers, paid per call

  1. A buyer's agent calls privi_verify_lot with a lot code.
  2. Verify replies with an x402 payment request: one cent in USDC on Base, paid to Privi.
  3. The agent signs the payment and calls again. No account, card or invoice.
  4. Manufacturers record each step of a lot with privi_record_event; buyers see the chain of custody with privi_chain_of_custody.

Privi Anchor

Proof that a record existed at a point in time

  1. Fingerprint any document with anchor_hash_text, or hash it yourself. Only the hash is used.
  2. Anchor up to 100 hashes in one call with anchor_hashes (free with an API key). They are combined into a Merkle root and written to Base.
  3. Anyone can call anchor_verify with the hash and get the transaction, block and time, with a Basescan link.

Privi Quantum

Optimize a factory decision, signed for the quantum era

  1. Call quantum_optimize with a ready-made problem, such as balancing jobs across two lines.
  2. Privi runs a quantum optimization algorithm (CVaR-QAOA) on a simulator and checks the answer against the proven best one.
  3. Every result is signed with Ed25519 and ML-DSA-87. Check it with quantum_verify.
  4. Run pqc_scan_code on your code to find cryptography a quantum computer could break, with the fix for each.

Honest limits: problems up to 16 qubits run on a simulator, where a classical computer can also solve them. This is a working path to quantum hardware, not a claim of quantum advantage today.
