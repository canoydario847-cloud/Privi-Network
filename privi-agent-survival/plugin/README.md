# Privi Network plugin

Made by Dario Canoy, Privi World Corp.

Connect a remote MCP client to `https://privi-ai-21-gateway.onrender.com/mcp`. This folder contains the portable plugin manifest and MCP configuration. To prepare an upload, run `zip privi-network.zip plugin.json mcp.json` from this folder.

## Paid use

Connecting and listing tools is public. Executing tools requires paid access. Standard utilities cost 1 prepaid credit and premium utilities cost 5. CallProof controls require a verified Pro entitlement and the appropriate role credentials. A directory listing or plugin installation grants no credits. Supply credentials only through a supported client's secure credential settings.

Check the [gateway pricing page](https://privi-ai-21-gateway.onrender.com/pricing) and [service status](https://privi-ai-21-gateway.onrender.com/health) before purchasing. While the gateway returns `paid_checkout_not_ready`, automated tools cannot run. The separately sold human services do not issue plugin credentials automatically.
