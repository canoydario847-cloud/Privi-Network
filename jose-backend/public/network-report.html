    How grading and credits work

    Each grade is computed from monitored HTTP availability, response speed, and the most recent probe results. A grade appears only after at least three fresh cycles; stale or missing data is marked unavailable. User heartbeats never increase the availability grade. Participation credits are account-level, rate-limited, capped daily, and not an on-chain asset.

    Always-on limitation: the five-second task runs only while Jose's backend process is active. On a sleeping or restarted free server, monitoring pauses and its recent history resets. For continuous 24/7 monitoring, use a persistent paid instance, external uptime checks, durable database and alert delivery.
