# Privi Car — First pilot qualification scorecard (prelaunch)

Use this worksheet for a **human-delivered, consent-first $19.99 proposed pilot**, not an automated checkout or live vehicle service. Store completed forms privately, never in GitHub.

## Five-minute prospect screen

- Business type: independent repair shop / fleet with 3–20 vehicles / other
- Records available: compatible local `fleet_batch.py` export / synthetic demo only / unknown
- Authorized to share: yes / no / unknown (require yes before intake)
- Desired result: identify duplicate, conflicting, decreasing, or integrity-invalid submitted mileage records / other
- Accepts limitations: advisory report only; no actual odometer authentication, live diagnostics, or certification: yes / no
- Willing to evaluate a **proposed** $19.99 one-time manual review after scope, transfer, retention, and delivery terms are agreed: yes / no / unsure

**Qualifies for pilot discussion only if** authorization is confirmed, compatible or synthetic input exists, limitations are accepted, and secure transfer and deletion are agreed. Otherwise offer a synthetic demonstration; do not request real data or payment.

## Delivery and conversion checklist

1. Explain the offer and get explicit consent outside the repository.
2. Agree on permitted fields, secure transfer, local access, and deletion date. Never request VIN, plate, owner name, location trails, credentials, or raw telemetry.
3. Run documented local tests before handling real records. Stop on failure.
4. Produce one aggregate report with a unique output path; never overwrite an existing report.
5. Explain one of: insufficient consented records / human review recommended / no anomalies detected in submitted records. Never imply verified vehicle history.
6. Ask whether the exact manual review is worth $19.99 and record a yes/no answer privately. Do not claim a sale without verified payment.

## Success measures (record privately)

Prospects contacted; replies; consented qualified pilots; reports delivered; customers expressing willingness to pay; **verified completed payments**; time spent per report. Keep counts separate; interest is not revenue.

It checks compatible, owner-authorized exported records for inconsistencies and provides an aggregate report. It does not verify actual vehicle mileage or connect to the car. Would you like to see a synthetic example first? Please don't send personal or vehicle-identifying data in a reply.

No live Smartcar integration, vehicle AI automation, fuel prepay, pump reservations, or vehicle-mining income is included. No payment or production deployment is implied. See CUSTOMER_PILOT_OFFER.md and PILOT_REPORT.md.
