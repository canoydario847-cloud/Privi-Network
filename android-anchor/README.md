# Privi Anchor for Android

A Trusted Web Activity (TWA) that opens the Privi Anchor web app (`https://privi-anchor.onrender.com/app/`) full screen in Chrome.
The same app installs from any browser ("Add to Home screen" / "Install app") without Google Play.

- Package: `us.priviflow.anchor`
- Origin: `https://privi-anchor.onrender.com` (the server serves `/.well-known/assetlinks.json` for it)
- Built by `.github/workflows/android-anchor.yml` (unsigned unless signing secrets are set)
- Generated by `apps/build.py` from `apps/apps.json`. Change those, not the files here.

## Release steps (owner only)

1. **Upload key.** On your computer: `keytool -genkeypair -v -keystore anchor-upload.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000`.
   Keep the file and password safe and off GitHub. Optionally add GitHub secrets `ANCHOR_KEYSTORE_B64` (base64 of the
   .jks) and `ANCHOR_KEYSTORE_PASSWORD` so the workflow signs the bundle for you.
2. **Build.** GitHub → Actions → "Privi Anchor Android app" → Run workflow. Download the `.aab` from the run.
3. **Play Console** (account PriviKing1) → Create app → "Privi Anchor", App, Free to download → upload the .aab to
   **Internal testing**.
4. **App signing fingerprint.** Play Console → Test and release → App integrity → copy the **App signing key
   SHA-256**. In Render, set `ANCHOR_ANDROID_SHA256` on privi-anchor to that value (comma-separate if you add the upload-key SHA-256
   too). Until this is set the app still works, but shows a browser bar at the top.
5. **Store listing, Data safety, content rating, privacy policy URL**, then roll out. Personal developer accounts
   must run a **closed test with at least 12 testers for 14 days** before Google allows a production release.

## Suggested listing

**Title:** Privi Anchor
**Short description:** Proof that a file existed on a date. Files never leave your device.
**Full description:** Privi Anchor gives you dated proof that a file existed, for designs, drafts, contracts, photos and research notes. The app fingerprints the file on your device (SHA-256), so the file itself is never uploaded. The fingerprint is anchored on the Base blockchain and you get a certificate with a public page. Anchor a whole folder with one transaction and later prove any single file was part of it. For customers with a Privi Anchor API key.
**Icon:** `play-store-icon-512.png` in this folder.

## Things to know before submitting

- Payment for the service happens on the web (a Privi key or plan, or USDC from a crypto wallet), not through
  Google Play billing. Check Google Play's current payments policy for your case before you submit.
- Pay-per-use with a wallet does not work inside the Play app itself, because Chrome on Android has no wallet. The
  app offers an "Open in MetaMask" link for that; customers with a key or plan are not affected.
