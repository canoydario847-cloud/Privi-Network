# Privi Verify MCP Server

Privi Verify lets AI agents check the provenance of manufactured goods for small manufacturers and their buyers.

## Features

- **Lot verification**: look up a lot or batch code and confirm its record is intact.
- **Chain of custody**: get every recorded event for a lot, in order.
- **On-chain checkpoints**: lot histories are anchored on the Privi Devnet, so any later change is detected.

## Pricing

`privi_pricing` is free and lists each tool's price. Paid lookups use x402 and settle in USDC on Base.
