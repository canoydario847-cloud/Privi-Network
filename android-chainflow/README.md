# Privi ChainFlow for Android

A Trusted Web Activity (TWA) that opens the Privi ChainFlow web app (`https://privi-verify.onrender.com/app/`) full screen in Chrome.
The same app installs from any browser ("Add to Home screen" / "Install app") without Google Play.

- Package: `us.priviflow.chainflow`
- Origin: `https://privi-verify.onrender.com` (the server serves `/.well-known/assetlinks.json` for it)
- Built by `.github/workflows/android-chainflow.yml` (unsigned unless signing secrets are set)
- Generated by `apps/build.py` from `apps/apps.json`. Change those, not the files here.

## Release steps (owner only)

1. **Upload key.** On your computer: `keytool -genkeypair -v -keystore chainflow-upload.jks -alias upload -keyalg RSA -keysize 2048 -validity 10000`.
   Keep the file and password safe and off GitHub. Optionally add GitHub secrets `CHAINFLOW_KEYSTORE_B64` (base64 of the
   .jks) and `CHAINFLOW_KEYSTORE_PASSWORD` so the workflow signs the bundle for you.
2. **Build.** GitHub → Actions → "Privi ChainFlow Android app" → Run workflow. Download the `.aab` from the run.
3. **Play Console** (account PriviKing1) → Create app → "Privi ChainFlow", App, Free to download → upload the .aab to
   **Internal testing**.
4. **App signing fingerprint.** Play Console → Test and release → App integrity → copy the **App signing key
   SHA-256**. In Render, set `CHAINFLOW_ANDROID_SHA256` on privi-verify to that value (comma-separate if you add the upload-key SHA-256
   too). Until this is set the app still works, but shows a browser bar at the top.
5. **Store listing, Data safety, content rating, privacy policy URL**, then roll out. Personal developer accounts
   must run a **closed test with at least 12 testers for 14 days** before Google allows a production release.

## Suggested listing

**Title:** Privi ChainFlow
**Short description:** Recall trace, Certificates of Conformance, NCRs and gauge calibration for small shops.
**Full description:** Privi ChainFlow replaces the paper quality records of a small manufacturer. Link each lot to the material it was made from, and list every lot a bad batch went into with one tap. Issue a Certificate of Conformance your customer can check. Attach mill test reports and inspection reports by fingerprint, so the files stay with you. Open and close non-conformance reports. See which gauges are due for calibration. Every entry joins the lot's tamper-evident history. For manufacturers with a ChainFlow key.
**Icon:** `play-store-icon-512.png` in this folder.

## Things to know before submitting

- Payment for the service happens on the web (a Privi key or plan, or USDC from a crypto wallet), not through
  Google Play billing. Check Google Play's current payments policy for your case before you submit.
- Pay-per-use with a wallet does not work inside the Play app itself, because Chrome on Android has no wallet. The
  app offers an "Open in MetaMask" link for that; customers with a key or plan are not affected.
