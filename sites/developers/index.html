CallProof is Privi’s flagship

Privi CallProof is designed to give AI-agent tool calls scoped permissions, budget ceilings, retry-safe intent reservations, separate approval for sensitive actions and cryptographically signed executor-reported receipts. Watch the 25-second flagship video or run the browser-only demonstration. Verified $35 one-time Privi Pro access is required for operational use; automatic API provisioning is not yet enabled, and the signature does not independently verify a third-party action.

Get started safely

  1. Choose a service

    Compare the six hosted MCP endpoints and find a tool that matches your agent workflow.

    Tool catalogs may be discoverable, but some execution paths require paid credentials or remain in evaluation. Do not send private keys or production data to an unverified service.

    Privi Guard Security Review costs $19.99 one time. A human coordinates scope and delivery; checkout does not automatically issue API keys.
