Connect your agent

For clients that support JSON MCP server settings (including Cline). Other clients may need an equivalent remote streamable-HTTP setting. Use the host app's secure settings for credentials.

{
  "mcpServers": {
    "privi-ledger": {
      "type": "streamableHttp",
      "url": "https://privi-ledger.onrender.com/mcp"
    },
    "privi-verify": {
      "type": "streamableHttp",
      "url": "https://privi-verify.onrender.com/mcp"
    },
    "privi-anchor": {
      "type": "streamableHttp",
      "url": "https://privi-anchor.onrender.com/mcp"
    }
  }
}

Your first three successful interactions

  1. Try without a key: call guard_pricing on Privi Ledger or mcp_server_check with {"url":"https://privi-verify.onrender.com/mcp"}.
  2. Create an organization: call ledger_signup with {"organization_name":"My Project"}. Store the returned api_key privately; it is displayed only once. Configure the Ledger server with Authorization: Bearer <api_key>.
  3. Write and read one genuine event: call ledger_record_action with {"stream_id":"first-agent","actor":"my-agent","action_type":"tool_call","summary":"Checked a tool with Privi","outcome":"success"}, then ledger_read_stream with {"stream_id":"first-agent"}. Only log actions that actually occurred.

Never put API keys, seed phrases or private customer data into public prompts. Keep human approval for spending and irreversible actions. The free Ledger plan is documented as 500 entries/month; Guard has separate usage limits.
