Four things, one live layer

Approvals and kill switch
Set a threshold and any payment above it waits for the mandate's human to sign approve or deny with their wallet. Your agent cannot approve itself. One call stops an agent's spending, gateways and rooms; the audit log keeps recording.
Trust feed
Passports issued, revoked and re-scored, wallets bound, mandates revoked and transparency-log heads anchored, pushed as they happen. Payment facilitators and marketplaces subscribe per wallet instead of polling.
Metered gateway
Put any public MCP server behind Privi. Every tool call is rate-limited, optionally Passport-gated, counted per tool and written to a tamper-evident log, over HTTP or one persistent WebSocket. x402 payments pass straight through.
Paid rooms
Two organizations' agents talk live in a hash-chained room. The guest pays per message under a human-signed mandate, and closing the room seals the transcript on the Privi chain for both sides.

Connect

// Browser or Node: watch your agents and the network
const ws = new WebSocket("wss://privi-ledger.onrender.com/live/ws");
ws.onopen = () => {
  ws.send(JSON.stringify({type: "auth", key: PRIVI_KEY}));
  ws.send(JSON.stringify({type: "subscribe", channels: ["org", "trust"], replay: 20}));
};
ws.onmessage = m => console.log(JSON.parse(m.data));

// Stop an agent, from anywhere
ws.send(JSON.stringify({type: "kill", stream_id: "shopping-agent", reason: "looping"}));
