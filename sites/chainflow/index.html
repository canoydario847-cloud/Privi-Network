How it works

Record events
Each receiving, production, inspection and shipping event is linked to the previous one by a SHA-256 fingerprint, so changing any past event breaks every fingerprint after it.
Label every lot
Each event gets a fingerprint and a public label page. Print the QR code on the box, pallet or certificate of conformance.
Anchored on chain
Every lot's latest fingerprint is checkpointed on chain (Base today; the Privi chain once its mainnet launches) every few minutes, so not even Privi can rewrite history unnoticed.
Paid per check
A label check is free. Buyers' agents pull the full chain of custody for a few cents in USDC on Base through x402, with no account.
Michigan first
Built in Port Huron for the manufacturers around it, open to anyone.
