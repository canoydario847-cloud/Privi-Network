### Description for international directories

Hey Jose is a web-based AI assistant by Privi World Corp. It brings everyday writing, explanations, coding help, and self-contained browser-app prototypes into one chat. The app includes 20 deterministic local tools for text privacy, cost calculations and data review; read-only, identity-verified Privi Devnet tools for public TEST data; file attachments, browser voice dictation and chat history. Gmail workflows are designed into the product but require the operator's Google OAuth setup and users' explicit authorization. Verified financial PRVI mainnet deployment is **not claimed**.
