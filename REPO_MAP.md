# Repo map: what each folder is

Nothing is moved on purpose: `render.yaml`, ~45 GitHub workflows and the MCP Registry publish job point at these paths. This file is the index.

**Pricing rule: every Privi tool is paid (x402 USDC on Base, or a paid API key). There are no free tiers.**

## Live MCP servers (deployed on Render via `render.yaml`)
| Folder | What it is |
|---|---|
| `ledger-server/` | Privi Ledger: audit logs, Guard, Scan, Passport, KYA, Mandates, Gov/PQC packs |
| `mcp-server/` | Privi Verify: lot verification and chain of custody |
| `anchor-server/` | Privi Anchor: hash anchoring on Base (paid API key) |
| `quantum-server/` | Privi Quantum: optimization, Inspector, RealCheck, Car, Bridge |
| `call-server/` | Privi Call: agent-call routing, call log, phone line |
| `wallet-server/` | Privi Wallet: custodial PRIVI/USDC wallets |
| `devnet/` | Privi EVM devnet node (not running; paused to save cost) |

## Discovery, distribution, sales
| Folder | What it is |
|---|---|
| `discovery/` | Source of truth for listings: `manifest.json`, `SUBMISSIONS.md` (copy-paste pack for directories) |
| `edge/` | Cloudflare Worker, global entry point |
| `sites/`, `privi-explorer.html` | Static websites and the Privi Explorer |
| `sales/`, `launch/`, `commercial/`, `GO_TO_MARKET.md`, `ADOPTION_LAUNCH.md` | Outreach, launch and go-to-market material |
| `privi-business-services/` | Human-delivered paid reviews ($99 / $149 / $249, Stripe) |
| `privi-agent-survival/` | Separate prepaid agent-utility gateway (older Render workspace) |
| `apify-actor/`, `skills/`, `integrations/`, `glama.json`, `llms-install.md` | Marketplace and client packaging |

## SDKs, tools, apps
| Folder | What it is |
|---|---|
| `guard-sdk/`, `gate-sdk/`, `cli/`, `examples/` | Client libraries, CLI, samples |
| `apps/` + `android-*` | One installable app per product (generated by `apps/build.py`); `android-world`, `android-realcheck` are the Play apps for Privi World and RealCheck |
| `privi-car/` | Privi Car platform (edge agent, fleet) |
| `compute-fabric/`, `quantum-school/` | Research prototypes, not deployed |

## Chain / token (separate from the paid MCP servers)
| Folder | What it is |
|---|---|
| `production-network/`, `mainnet/` | Cosmos EVM "Privi Foundation" chain and mainnet gating (not launched) |
| `ops/`, `security/`, `scripts/` | Runbooks, security docs, helper scripts |
